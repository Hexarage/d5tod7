# Producing a d7 result by using a d5

Study project on preserving entropy in random number generation

Used: https://algo.inria.fr/seminars/sem94-95/hoshi.pdf as a resource to produce this

# Running

This was developped and ran on linux with g++, if you're looking at this you can easily switch it out for your preferred OS/Compiler

```bash
g++ main.cpp -o diceplay -O3 -std=c++23
./diceplay
```
